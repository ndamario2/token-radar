A token launch radar that ranks the 758 protocols DefiLlama tracks by what their token would be worth if it launched today — 198 pre-token protocols, each with a value breakdown and a concrete farm plan, on an offline dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
